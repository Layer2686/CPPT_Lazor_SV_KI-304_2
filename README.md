## Запуск початкової програми

Потрібен JDK 21. Із кореня репозиторію на Linux, macOS або Windows:

```text
java -version
java src/main/java/Main.java
```

Очікуваний результат — 67 рядків `Hello, world!`.
Java запускає вихідний файл без окремої команди компіляції.

У проєкті вже є початковий `pom.xml`. Повну збірку через Maven Wrapper,
тести, SpotBugs і виконуваний JAR налаштуємо під час виконання плану.

## Завдання лабораторної роботи № 1

Майбутня програма читатиме файл UTF-8 без заголовка, один запис у рядку:

```text
date;temperature;humidity;pressure;wind
2026-09-01;-5.5;70.0;1013.0;3.2
```

Назви полів у першому рядку прикладу пояснюють формат і не є рядком даних.
Одиниці, які зафіксуємо для цього проєкту: температура — °C, вологість — %,
тиск — гПа, швидкість вітру — м/с. Десятковий роздільник — крапка.

Програма має обчислювати:

1. Кількість коректних записів.
2. Мінімальну температуру.
3. Середню вологість.
4. Найбільшу швидкість вітру.

Некоректні рядки супроводжуватимуться повідомленням із номером і причиною
пропуску. Результат потрібно вивести в консоль і записати у файл.
Майбутні параметри запуску: `--help`, `--input`, `--output`, `--version`.
